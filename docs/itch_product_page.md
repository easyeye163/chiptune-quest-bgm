## Full description

**CHIPTUNE QUEST Vol.1** is a game-ready 8-bit BGM library built by a custom Python synthesis
engine — the same way classic NES composers worked, note by note, voice by voice. Every melody
is original. Every loop is seamless. Every file drops straight into your engine.

### What's inside
- **15 tracks (~13.5 min)**: 13 seamless loops + 2 one-shot stingers
- **3 themed suites**:
  - *Battle & Advance* — field battle (140 BPM), hopeful world-map march, 164 BPM skirmish,
    tense danger theme, warm campfire rest
  - *Knights' Banner* — SRPG-style player-phase march (B♭ major), enemy assault with
    leading-tone call & response, dark final-boss theme with triangle doubling,
    victory fanfare + level-up jingle
  - *Exotic Journey* — Hijaz desert caravan with maqsum groove, Hirajoshi shrine with taiko,
    double-harmonic ruins, tresillo (3+3+2) festival dance, pentatonic harbor bazaar
- **Formats**: OGG (Q6, engine-ready) + MP3 (192k) + **MIDI for every track**
- **48 kHz stereo, peak-normalized to −3 dBFS**, consistent loudness across the library

### Why seamless loops matter
Each loop track is synthesized at an exact bar boundary, with the decay tail wrapped back onto
the first bar — so when your engine loops the file, there is no gap, no click, no audible seam.
Loop lengths are pre-computed in `TRACKLIST.csv` for engines that accept explicit loop points.

### MIDI included
Every track ships with a General-MIDI-mapped .mid file (lead, harmony, bass, drums on separate
channels) — remix, rescore, or drop it into your own soundfont pipeline.
